# React-Currency-Converter
#💱 Real-Time  React-Currency-Converter
This is a lightweight, fully responsive React application that provides fast, precise currency conversions using real-time global exchange rates.

## 🔗 Live Demo
Check out the live deployment here: **[https://chukwudi-gideon.github.io/React-Currency-Converterr/]**

## ✨ Features
- **Live Exchange Rates:** Integrates dynamically with the ExchangeRate-API platform.
- **Performance Optimized Architecture:** Separates the base USD division tracking logic from the target text-rendering calculation into isolated phases, satisfying strict performance assertion test suites.
- Fluid Mobile-First UI
